7)Types of Access Modifiers : Public, Protected, Default, Private

# public :
The public members can be accessed from anywhere (if the class is visible/imported).

# default (package-private) :
When no access modifier is written, it gets default access.
It can be accessed only within the same package.

# private :
The private members can be accessed only inside the same class, not from outside directly.

#IMP NOTE = You can't define a class as private it could be either public or default.
